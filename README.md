# Audown

Youtube audio downloader.

**Tags:** `python` `wip`

## Requerimentos

* Python 3
* FFmpeg

## Instalação

Clone o repositório:

```bash
git clone https://github.com/carolsavio/audown.git
cd audown
```

Instale os requerimentos:

```bash
python3 -m pip install -r requirements.txt
```

Execute o script:

```bash
python3 audown.py
```
